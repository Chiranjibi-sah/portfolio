About me

I am a Computer Science Engineering graduate based in Kathmandu, Nepal. I recently completed my bachelor's degree at Kalinga Institute of Industrial Technology (KIIT) in India with a CGPA of 8.43/10, and I am now focused on starting a career in cybersecurity.

What interests me most is seeing security from both sides. I want to understand how vulnerabilities are discovered and validated, and how the same attacks appear in logs, get detected and are contained. That is why I follow a Purple Team path instead of choosing only offence or only defence.

I build practical knowledge through cybersecurity labs, self-directed learning, and projects I plan to build. I try to work with curiosity, careful analysis and discipline, and I test only systems I own or have permission to test. I am looking for internship and entry-level opportunities where I can keep learning from experienced teams.

Offensive and defensive security

Purple Team work connects the two sides. Offensive testing shows what is possible, and defensive monitoring shows whether it would be noticed. These are my learning areas, not claims of professional experience.

Offensive security

Red Team. Understanding attacker techniques, performing authorized security testing, identifying weaknesses, and validating vulnerabilities in controlled environments.

Learning focus

  • Reconnaissance and information gathering
  • Networking and service enumeration
  • Web application security testing
  • HTTP requests and responses
  • Burp Suite fundamentals
  • OWASP Top 10 concepts
  • Vulnerability identification and validation
  • Basic scripting for security tasks
  • Authorized penetration-testing labs

Defensive security

Blue Team. Monitoring logs, investigating suspicious activity, identifying attacks, improving detection rules, and understanding incident response.

Learning focus

  • Linux and networking fundamentals
  • Security log analysis
  • Failed-login investigation
  • Suspicious authentication patterns
  • Basic incident investigation
  • Security monitoring and detection fundamentals
  • Firewall and access-control concepts
  • SIEM fundamentals
  • Incident response concepts

Purple Team

Both sides together. Connecting offensive testing with defensive detection to improve an organization's overall security.

Learning focus

  • Mapping attack techniques to defensive detections
  • Validating whether suspicious activity produces useful alerts
  • Recognising attack indicators in logs
  • Identifying detection gaps
  • Recommending improvements to monitoring and controls
  • Learning how offensive testing can strengthen defence
